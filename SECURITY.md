# Security

This project modifies a local Codex runtime script. Treat it as a temporary workaround, not a supported vendor patch.

Safety rules:

- Only use proxy endpoints you own or trust and are authorized to use.
- Never publish proxy credentials, browser cookies, tokens, account IDs, or private logs in issues.
- Never disable TLS verification to make this workaround work.
- Never disable system-wide security controls just to fix Browser Use.
- Always keep a timestamped backup before patching.
- Revert the patch before reporting unrelated Codex runtime bugs if you need a clean baseline.
